# Rut persistence: the simulated window slides over the world in tiles and
# keeps every rut it leaves behind.
#   1. focus a 40 m window (10 m tiles, 3.9 cm cells) and follow the wheel
#   2. drive a straight line north across four tiles cutting a rut
#   3. slide the window back to where the rut started: the rut must still be there
#   4. drive back south along the same line: the second pass deepens the rut
#   5. audit: ground + air + tiles out of the window must equal the baseline
# The pad runs Y = -30..30 at X = 3. Heading 90 deg = +Y.

wait 2 startup
DaDirt.Mode testbed
sun -22 35
DaDirt.Reset
wait 1

# --- 1. window on the south end of the pad -----------------------------------------
DaDirt.Focus 3 -15 40
wait 1
DaDirt.Info
DaDirt.Wheel 3 -26 90
DaDirt.Focus follow
DaDirt.Follow 1
wait 0.5
DaDirt.Audit

# --- 2. north across the tiles -------------------------------------------------------
DaDirt.Drive 0.5 0 0
wait 4 pass_north_a
screenshot persist_00_driving
wait 8 pass_north_b
DaDirt.Drive 0 0 1
wait 2
DaDirt.Info
DaDirt.Follow 0
DaDirt.Audit

# --- 3. back to the start: is the rut still there? -----------------------------------
DaDirt.Focus 3 -15 40
wait 1
DaDirt.Info
DaDirt.Probe 2.7 -20
DaDirt.Probe 2.88 -20
DaDirt.Probe 3 -20
DaDirt.Probe 3.12 -20
DaDirt.Probe 3.3 -20
DaDirt.Probe 3 -10
DaDirt.Probe 3 -22
camera 3 -26 0.9 -12 90
wait 0.4
screenshot persist_01_rut_kept
DaDirt.Audit

# --- 4. the return pass --------------------------------------------------------------
DaDirt.Focus 3 15 40
wait 0.5
DaDirt.Wheel 3 14 270
DaDirt.Focus follow
DaDirt.Follow 1
wait 0.5
DaDirt.Drive 0.5 0 0
wait 12 pass_south
DaDirt.Drive 0 0 1
wait 2
DaDirt.Follow 0
DaDirt.Probe 2.7 -20
DaDirt.Probe 2.88 -20
DaDirt.Probe 3 -20
DaDirt.Probe 3.12 -20
DaDirt.Probe 3.3 -20
DaDirt.Probe 3 -10
camera 3 -14 0.9 -12 270
wait 0.4
screenshot persist_02_two_passes
DaDirt.Info
DaDirt.Audit

# --- 5. widen back out: everything folds into the whole box ---------------------------
DaDirt.Focus off
wait 1
DaDirt.Audit
quit
