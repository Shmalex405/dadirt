# DaDirt soil-strength test (docs/SoilPhysics.md, Phase A).
# The testbed's 100 m3 block at (3,45) is 1 m tall with vertical walls, compaction
# 0.1, moisture 0.05. Same block, three states:
#   1. as built, barely damp   c ~ 1.4 kPa -> Culmann vertical height ~60 cm: the top
#                              of the wall should shear off, the bottom ~60 cm stand
#   2. dampened to ~0.4        c ~ 3.8 kPa -> vertical height ~1.6 m: the wall stands
#   3. soaked                  c -> 0, friction x0.4 -> mud at ~14 deg: it runs out
# The dry cone at (3,-45) is the control: moisture 0, no cohesion, must still go to 32 deg.
# Probes cross the X = 8 wall at Y = 45; the pad is at 60 cm, the block top at 160.

wait 2 startup
